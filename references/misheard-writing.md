# 空耳创作

在生成候选前读取本文件。目标不是随便改字，而是让听觉、字幕和画面同时成立。

## 评分标准

每个候选按以下五项判断：

1. **音近**：声母和韵母尽量接近，声调可适度放宽。宁可只换一个字，不要为了换满全句而
   牺牲读音。
2. **可画**：改出的词必须能直接变成主体、道具或动作。“葱刺”能画成大葱刺出；
   “层次”没有明确动作，不合格。
3. **荒诞反差**：深情、宏大或温柔的原句，优先配日常食材、动物、笨拙动作等强反差物。
4. **一句一梗**：通常只换 1–2 个词。保留原句结构，让观众先认出旋律再发现不对。
5. **画面可在一个镜头完成**：主体少、动作单一、五秒左右能看懂。

建议给每项 1–5 分。优先保留音近和可画均不低于 4 分的候选。

## 节奏

- 主歌允许保留 1–2 句原词作为铺垫。
- 副歌提高梗密度，但仍不强迫每句改写。
- 连续两句避免重复同一种主体或同一种笑法。
- 一句若没有自然、可画的空耳，提供“保留原词”，不要硬凑。

## 候选结构

在 `plan.json` 的每个 `lines[]` 项中保留：

```json
{
  "candidates": [
    {
      "label": "A",
      "misheard": "含煤好好的感受",
      "visual": "古装女子嘴里含着一块煤，对着麦克风认真唱歌",
      "prompt": "……",
      "scores": {
        "phonetic": 5,
        "visual": 5,
        "contrast": 4
      }
    }
  ]
}
```

候选的 `prompt` 可以先写到可确认的程度；用户选定后再按
`references/video-prompts.md` 收紧为最终生成 Prompt。

## 用户确认表

```text
| # | 时间 | 原词 | 候选A | 候选B | 候选C |
|---|------|------|-------|-------|-------|
| 1 | 0:12–0:16 | 还没好好地感受 | 含煤好好的感受 | 韩梅好好的感受 | 保留原词 |
```

同时说明：

- 可回复 `1A 2B 3C`。
- 可回复 `3自定义：……`。
- 可要求某一句重写候选。
- 所有行确认前不会生成视频。

## 禁区

- 不写低俗性暗示或露骨内容。
- 不写政治人物、政治事件或煽动性内容。
- 不用真人明星的外貌制造羞辱、造谣或欺骗性画面。
- 不把受保护群体身份当笑点。
- 不用复杂文字、品牌标识或精确手部细节作为笑点成立的唯一条件。
