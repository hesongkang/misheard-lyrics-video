# 文生视频 Prompt

在候选确认后、首次生成或重试前读取本文件。

## 固定目标

- 模型：`doubao-seedance-2-pro`
- 比例：9:16
- 分辨率：1080p
- 时长：读取计划中的 `generation_duration_s`，范围 3–15 秒
- 单镜头、单一可读动作
- 生成画面不承担音频；最终统一静音并使用原曲

## Prompt 结构

按以下顺序写成一段自然语言：

```text
[最重要的主体与关键道具]
+ [一个明确动作，直白执行空耳字面意思]
+ [地点与空间关系]
+ [适合该梗的视觉风格]
+ [竖屏构图与主体大小]
+ [镜头在时长内如何开始、完成和停住]
+ [必要的排除项]
```

示例：

```text
一名严肃的古装女歌手，嘴里清楚含着一整块黑色煤块，仍然对着老式麦克风深情演唱。
中式宫殿舞台，写实电影光线，荒诞但一本正经。9:16 近景，人物和煤块始终清晰，
五秒内只完成抬头、含煤唱一句、定格看向镜头的动作。不要字幕、不要水印、不要多人、
不要现代品牌标识。
```

## 写法规则

- 在第一句同时写出主体、道具和动作；不要把关键梗放到 Prompt 末尾。
- 用具体数量和位置替代抽象形容词，例如“一只巨型蚊子站在野猪背上揉搓肩膀”。
- 让相机服务可读性：主体梗小则近景，涉及追逐或冲刺则中远景。
- 画面风格随梗走。古装、写实、怪兽片、新闻纪录片、舞台剧可以相邻出现。
- 不要求模型在画面里生成歌词或任何可读文字；字幕由 HyperFrames 添加。
- 不写多个连续事件、镜头切换或复杂因果链。
- 不依赖微小手指、精确口型或模型难以稳定生成的文字。

## 按失败原因最小重写

首次失败后只强化缺失部分：

| 失败 | 修改方式 |
|---|---|
| 主体错误 | 把正确主体放到第一词，删除竞争主体，增加数量与外形 |
| 道具不明显 | 放大、提高对比、说明手持/口含/背负等空间关系 |
| 动作错误 | 改为一个动词，写清动作起点和终点 |
| 画面太乱 | 限制单主体、固定机位、删除背景群众与次要事件 |
| 梗读不出来 | 改为近景或中景，让字面对象占画面主要区域 |
| 构图不适合字幕 | 主体上移，底部约 22% 保持低细节安全区 |

每镜最多两个重写版本。第三个生成结果仍不合格时，不再调用模型；从已有三版中选择最佳。
